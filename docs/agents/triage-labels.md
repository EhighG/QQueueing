# Triage Labels

스킬은 트리아지 역할 다섯 가지를 기준으로 말한다. 이 파일은 그 역할을 이 저장소 이슈 트래커의 실제 라벨 문자열에 연결한다.

| mattpocock/skills의 라벨 | 우리 트래커의 라벨 | 뜻                                       |
| ------------------------ | ------------------ | ---------------------------------------- |
| `needs-triage`           | `needs-triage`     | 메인테이너 검토가 필요한 이슈            |
| `needs-info`             | `needs-info`       | 보고자에게 추가 정보를 기다리는 중       |
| `ready-for-agent`        | `ready-for-agent`  | 명세가 끝나 에이전트가 바로 작업할 수 있음 |
| `ready-for-human`        | `ready-for-human`  | 사람이 직접 구현해야 함                  |
| `wontfix`                | `wontfix`          | 처리하지 않음                            |

스킬이 역할을 언급하면(예: "apply the AFK-ready triage label") 이 표에서 대응하는 라벨 문자열을 쓴다.

트래커에서 실제로 쓰는 라벨 이름이 바뀌면 가운데 열(우리 트래커의 라벨)을 고친다.
